# Mitarbyte KI-OS — user-onboarding (Kanal `v2-lts`)

Fassung des user-onboarding-Skills für **bestehende Firmen-VMs auf dem Stand
`v2-lts`** (mit noVNC-/Cockpit-Tunnel und Mutagen-Sync). Neue Kunden
nutzen den Live-Kanal auf `main`.

**macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/Mitarbyte/marketplace/v2-lts/install.sh | bash`

**Windows (PowerShell):** `irm https://raw.githubusercontent.com/Mitarbyte/marketplace/v2-lts/install.ps1 | iex`

Danach Claude Code starten und `/user-onboarding` eingeben.

> Automatisch generiert aus `ki-os-template` (Zweig `v2-lts`, 07b0694b) via
> `scripts/sync-onboarding-plugin.sh --ref v2-lts`. Hier nichts von Hand editieren.
